## CDNs:

### `arena_collection.json`

The user's MTG Arena collection — an array of `[cardId, ownedQuantity]` pairs, sorted by card release date.

https://cdn.jsdelivr.net/gh/FormeOrme/mtg-collection@latest/data/generated/arena_collection.json

### `scryfall_arena_data.json`

Scryfall oracle card data with basic fields: stripped name, rarity, color identity, and an Arena availability flag.

https://cdn.jsdelivr.net/gh/FormeOrme/mtg-collection@latest/data/generated/scryfall_arena_data.json

### `scryfall_barebone.json`

Extended Scryfall card data in a compact format, including Standard format legality status (0 = not in Standard, 1 = in Standard, 2 = leaving Standard).

https://cdn.jsdelivr.net/gh/FormeOrme/mtg-collection@latest/data/generated/scryfall_barebone.json
